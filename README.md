# Iron Caravan: Offline

Одиночная игра на Godot: пикап, покупаемые прицепы, экипаж, добыча и шесть волн противников. Запуск работает без сервера и Node.js. Документация сверена с рабочим деревом 6 сентября 2026 года.

## Запуск

Откройте [project.godot](project.godot) в Godot и нажмите F5, затем **SINGLEPLAYER → RAID**. Проект проверялся с Godot 4.7.2. По умолчанию интерфейс английский; язык выбирается в Options.

## Меню и рейд

Главное меню: **Singleplayer**, отключённый **Multiplayer**, **Options**, **Exit**. В Singleplayer пункт **Vault** открывает единый экран с вкладками **Armory**, **Stash**, **Vault**, **Trade**, **Base**, **Tasks**, **Settings**. Vault хранит добычу между рейдами, Stash содержит припасы для следующего выезда. Options доступны также с паузы и сохраняют звук, язык и силу тряски камеры.

В рейде собирайте добычу, улучшайте вооружение и выполняйте задания. Для сохранения груза въезжайте в зелёную зону эвакуации, нажмите E и защищайтесь внутри 20 секунд. Победа также сохраняет груз; гибель и отказ от рейда его теряют. Подробные правила: [добыча и убежище](docs/expedition-gameplay.md), [караван и экипаж](docs/caravan-crew-implementation.md), [задания](docs/missions.md).

## Управление

| Клавиша | Действие |
| --- | --- |
| WASD, Shift | Движение, ручной тормоз/дрифт |
| F или короткий клик по врагу | Приоритетная цель |
| 1 / 2 / 3, Space | Выбор навыка, применение; клик по слоту применяет сразу |
| E | Взаимодействие; удержание для взлома мины при установленном модуле |
| I / Tab | Груз в рейде, убежище в главном меню |
| B | Арсенал |
| J / C | Экипаж / команда сбора добычи |
| M | Масштаб миникарты |
| P / Esc | Пауза или закрытие текущего экрана |

Перезапуск доступен в паузе; R не привязан. Сенсорные кнопки показываются на устройствах с сенсорным экраном.

## Разработка и проверки

```sh
python3 tests/run_all.py --godot /path/to/Godot
```

Путь к движку также можно задать через `GODOT_BIN`. Правила проверки, сохранённые результаты и экспорт описаны в [testing.md](docs/testing.md). Headless проверяет логику и ошибки движка, а изображение, звук и управление требуют отдельной проверки.
