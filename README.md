# Iron Caravan: Offline

Одиночная игра на Godot: пикап, прицепы, экипаж, добыча, задания и шесть волн врагов. Сервер и Node.js для игры не нужны.

Откройте [project.godot](project.godot) в Godot 4.7 и нажмите F5, затем Singleplayer → Raid. Vault открывает общее убежище для подготовки. По умолчанию язык английский, русский выбирается в Options.

WASD: движение. Space/Shift: ручник. Q: приоритетная цель. 1/2/3: выбрать способность, F: применить. E: взаимодействие. B: арсенал. I/Tab: груз. J: экипаж, C: сборщики. M: карта. P/Esc: пауза.

Для эвакуации въезжайте в зону, нажмите E и удерживайтесь внутри 20 секунд. Радар пятого уровня раскрывает зоны на миникарте; сами зоны доступны без него. Эвакуация и финальная победа сохраняют груз, гибель и отказ от рейда его теряют.
