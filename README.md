# Iron Caravan: Offline

Последний проход: отзывчивое управление и согласованное обновление камеры/машины, ровный кузов, радар с четырьмя уровнями и следы шин по поверхности. Headless44/44. Новые правки подготовлены к переносу в основной проект. Подробности и установка: [docs/handling-radar-trails-pass.md](docs/handling-radar-trails-pass.md).

Текущая рабочая копия содержит новый компактный HUD, карту с начала игры, исправленные меню, countdown и следы взрывов. **В исходную папку изменения ещё не установлены.** Свежие проверки: [ui-repair-pass.md](docs/ui-repair-pass.md).

Одиночная версия Iron Caravan для Godot 4.7.2. Откройте `project.godot` и нажмите F5, затем `START RUN`. По умолчанию интерфейс английский; русский выбирается в главном меню или паузе и сохраняется. Интернет и Node.js для запуска не нужны.

Каждый новый заезд строит новый мир по случайному seed целиком в GDScript. Работают исходная арена радиусом 1248, машина, камера, дрифт, топливо, столкновения, оружие, враги, шесть волн и босс. Арсенал покупает реальные модули, улучшения, оружие и прицепы. Повышение уровня останавливает бой для выбора улучшений. Статистика заездов сохраняется в локальном профиле. В главном меню больше нет контрактов. Погода влияет на сцепление и дальность; объекты разрушаются, станции заправляют машину, выход за границу даёт 15 секунд на возврат.

## Управление

- WASD: движение, Shift: дрифт.
- F или короткий клик по врагу: приоритетная цель. Перетаскивание не выбирает цель.
- 1, 2, 3: выбрать нитро, таран, ремонт. Space: активировать. Клик по слоту сразу применяет навык.
- E: удерживать для взлома мины; возле подходящего поселения запросить эвакуацию.
- B: арсенал. P / Esc: пауза. Новый заезд: кнопка `RESTART RUN` в паузе; R не привязан.
- M: масштаб миникарты. Карта видна сразу; модуль радара расширяет обзор.

## Предыдущая установка (до текущего прохода)

**Установлено в целевой проект; запуск установленной версии через MCP подтверждён.** Свежий Metal reference сравнен с исходником: геометрия и дороги совпадают, Godot немного светлее и тени слабее. Графический benchmark на Apple M4 Pro при1280×800 показал p95 около8.5–14мс, но также задержки826мс при первом показе поселения и140мс в фазе первых выстрелов. Задержки первого использования остаются; плавная загрузка без зависаний не подтверждена. Ручной полный забег и прослушивание ещё нужны.

Подробные результаты, память, ограничения и статус экспорта: [проверка и установка](docs/deployment-validation.md). [Исходный benchmark JSON](docs/validation/render-benchmark.json).
