# Происхождение и назначение изображений

`references/originals/` — десять исходных скриншотов, предоставленных пользователем.

`assets/` — небольшие предметы, портреты и прицеп, выделенные из этих скриншотов, плюс фрагмент генеративного фона. Они нужны для визуальной преемственности макетов. Их присутствие не означает, что это полноценные исходные игровые ассеты с подходящим разрешением для любого экрана.

`concept/ai-direction-board.png` — концепт, созданный доступным инструментом генерации изображений в этом сеансе. Выбор версии «GPT 2.5 Image» не был доступен. Конкретная версия модели не подтверждена. Не переносить из концепта случайные названия, числа, классы креплений и нарисованные прицепы в игровую логику.

`assets/hero-scene.png` — фрагмент этого концепта для главного меню. Для выпуска игры его следует заменить финальным изображением/рендером нужного разрешения, сохранив композицию.

Низкополигональная сцена в рейдовых SVG и векторный пикап — графические заместители, написанные для макетов. Это не скриншот новой сборки игры и не предложение заменить существующий 3D-рендер плоской иллюстрацией.

Все подписи и элементы управления в `source/svg/` — редактируемые векторы и текст. PNG отрисованы из тех же SVG. Файлы шрифтов отсутствуют. Установленный Inter использовался при экспорте; резервный шрифт может изменить ширину текста на другой машине.
