# Машины поддержки, помехи и взлом мин

2026-09-05. Сборка: `/private/tmp/iron-godot-finish-9siuihzq`.

Глушитель теперь появляется с волны2; ремонтный краулер и минный заградитель с волны3. В каждой последующей волне по одному каждого открытого типа. Они вставлены между обычными противниками, учитываются при завершении волны и проходят прежние лимиты спавна. Количества:9/18/26/33/38/46. [Таблица](enemy-audit-notes.md).

Помехи действуют в48м по XZ, полная сила в24м. Вход сглаживается; каждые3.2с после1.6с предупреждения происходит импульс длительностью0.5с. Инвертируются только газ/руль, ручник остаётся доступным. Точность получает дополнительный разброс до±6° по силе помех. Смерть, оглушение глушителя или выход из зоны немедленно возвращают обычное управление/точность; остаточная картинка коротко затухает. Ближний подход важен: слабая внешняя часть зоны не переворачивает управление. [Механика](jammer-gameplay-notes.md).

Видимый эффект: тонкие волны у источника, искры у машины и компактная подпись EN/RU. Нет сплошной полноэкранной заливки. Материалы учитывают глубину; количество объектов фиксировано, прогрев не запускает механику. Радар и экранные указатели используют тот же источник помех; также исправлено постепенное затухание тумана для указателей. [Эффекты](jammer-feedback-notes.md).

В арсенале доступен **Mine Hacking Kit**, стоимость60лома, вес2, один на караван. После установки нужно подойти к вооружённой мине на4.5м и удерживать E3секунды. Отпускание кнопки, уход, смена мины, потеря модуля или пауза сбрасывают прогресс. Зелёная мина не реагирует на игрока/союзников и срабатывает только на врагов. Модуль включён в загрузку/прогрев; его определение сохраняется при повторном экспорте каталога TypeScript. [Взлом](mine-hacking.md).
