# Выбор моделей врагов

Откройте `index.html` напрямую или через локальный HTTP-сервер. Страница работает без CDN и интернета: вращение мышью, общий ракурс A/B, пять цветов, сравнение с настоящей моделью игрока, пример градиентов деревьев и снимки Godot.

Для каждого из шести машинных типов созданы `field` и `armored` через Blender MCP. Дроны, мотоцикл и прежние обломки не пересобирались. По выбору пользователя всем шести типам назначен B (`armored`), деревьям оставлен градиент. В игре используются варианты и цвета из `data/enemy_vehicle_styles.json`. Кнопки страницы сохраняют выбор только в браузере; «Скачать мой выбор» выгружает полный конфиг. Для применения замените им этот JSON и перезапустите игру.

Один источник вариантов, масштабов и цветов: `data/enemy_vehicle_styles.json`. GLB и исходники Blender: `assets/models/enemies_revised/`; игровые копии экспортируются в `assets/actors/enemies_revised/`. Сборщик `scripts/blender/build_enemy_revision.py` расширяет общие factories из `enemy_vehicle_bodywork.py` и `build_military_enemies.py`. Неподвижные детали объединены, подвижные части и пять якорей босса сохранены.

Вызов из Blender MCP на чистой сцене:

```python
import runpy
r = runpy.run_path('/Users/fosterushka/Work/vibe/roguelike_godot/new-game-project/scripts/blender/build_enemy_revision.py')
r['setup']()
for model in r['STYLE']['models']:
    for variant in r['STYLE']['variants']:
        r['build_one'](model, variant)
r['finish']()
```

Деревья пересобираются `scripts/blender/build_textured_trees.py`, веб-буферы игрока и деревьев обновляет `scripts/blender/export_review_references.py`. `models.js` и `references.js` являются экспортом настоящих мешей, а не отдельными моделями для веба.

Пресет можно менять кодом для отдельной обычной модели:

```gdscript
var model := SourceModel.instantiate("buggy")
MilitaryEnemies.apply_preset(model, "slate")
```

`apply_preset()` задаёт material_override на экземпляре; общие меши не изменяются. Материалы пресетов кешируются. Для MultiMesh override применяется ко всему пулу, а не отдельной машине внутри пула. Выбор варианта доступен через `MilitaryEnemies.templates("buggy", "armored", "oxide")`; штатный SourceModel читает вариант из конфигурации при первой загрузке.

Проверено: 8/8 файлов тестов через `tests/run_all.py`, отчёт `docs/validation/enemy-vehicle-review/report.json`. Проверки охватывают оба варианта всех машин, лимиты геометрии, колёса, узлы босса, изоляцию перекраски, градиенты, галерею и загрузку. Реальный рендер Metal/Forward+ создал семь снимков через `tests/enemy_vehicle_revision_capture.gd`. Страница открыта в Safari; проверены отображение A/B, выбор цвета и варианта, сравнение деревьев.

Обычные машины: 3592–4876 треугольников; Левиафан: 4264–4488. Ель: 116, берёза: 388, по одной поверхности. Количество частей указано в интерфейсе; это не замер draw calls, поскольку игровой контур и тени добавляют проходы. Замеры FPS и длительный игровой прогон не проводились.


## Левиафан: пересборка с нуля

Новая форма: низкий клиновидный корпус, длинная сдвоенная пушка, два плечевых ракетных блока, кормовой реактор и широкие гусеницы. `scripts/blender/leviathan_bodywork.py` использует общие hull/panel/cylinder builders; прежняя функция boss теперь вызывает этот единственный сборщик. Вариант B имеет 4488 треугольников против 6200 у предыдущего B (на 27,6% меньше), шесть частей и один общий материал.

`data/leviathan_geometry.json` хранит якоря узлов, радиусы и лимит треугольников. Blender и `modules/combat/leviathan_geometry.gd` используют одни данные; точка ракеты находится на левом пусковом блоке. Масштаб остаётся в общем каталоге вариантов. Попадания и выстрелы теперь привязаны к новому низкому корпусу. Целые узлы видны во всех фазах, но защищённые узлы остаются недоступными для урона; исчезают только уничтоженные.

Финальные проверки пересборки: 8/8 файлов в `docs/validation/leviathan-rebuild/report.json` (геометрия/якоря/видимость, высота над землёй, AI и фазы, бой, отображение боя, полный автоматический прогон, деревья и загрузка). Реальный Metal-рендер спереди, сзади и сверху: `boss-hero-godot.png`, `boss-rear-godot.png`, `boss-top-godot.png`. Снимки проверены визуально. Повторная UI-автоматизация Safari остановилась на ошибке подключения инструмента; HTTP-выдача страницы и синтаксис JS проверены. Исходная версия интерактивной страницы была проверена в Safari ранее.
