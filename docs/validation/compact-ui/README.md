# Архив проверки компактного UI

Описание актуализировано 2026-09-06. Снимки и отчёты относятся к объединению вкладок и исправлению HUD. Текущие компоненты описаны в [ui.md](../../ui.md), общий порядок проверки в [testing.md](../../testing.md).

## Что было проверено

Общий Hideout объединяет Armory, Stash, Vault, Trade, Base, Tasks и Settings. Кредиты и уровень видны в заголовке; Garage возвращает на выбранную вкладку. Описание арсенала прокручивается. Сенсорные кнопки больше не появляются на ПК из-за узкого окна. Иконки и запрос генерации находятся в [assets/ui](../../../assets/ui/README.md).

| Отчёт | Сохранённый результат |
| --- | --- |
| [full-suite.json](full-suite.json) | 78/78, полный набор на момент UI-прохода |
| [final-check.json](final-check.json) | 8/8, профильные проверки после интеграции и визуальных исправлений |
| [last-sizing.json](last-sizing.json) | 3/3, последние размеры кнопок и смена языка |

Это исторические результаты: текущий список тестов расширен и описан в [testing.md](../../testing.md). При обновлении документации повторного прогона не было.

## Снимки и ограничения

Кадры получены на Godot Metal Forward+ / Apple M4 Pro, английском и русском, 960×600 и 1280×800. Сценарий: [compact_ui_capture.tscn](../../../tests/compact_ui_capture.tscn).

[Арсенал EN 1280](armory-en-1280.png) · [Арсенал RU 960](armory-ru-960.png) · [Stash](stash-en-960.png) · [Vault](vault-en-960.png) · [Торговля](trade-ru-960.png) · [База](base-en-960.png) · [HUD EN](hud-en-960.png) · [HUD RU](hud-ru-960.png).

Снимки сделаны перед тремя небольшими правками: ширина действий инвентаря 116→145, обновление языка подписи крепления и иконка выбора языка. Повторный захват остановлен после зависания подготовки графики; эти правки прошли профильные тесты. После UI-прохода модель пикапа также менялась: снимки не доказывают вид новой модели.

Отдельные headless-проверки размеров HUD и арсенала включали 960×540 и 1280×720. Это проверки границ, а не графические снимки таких размеров. Экспорт приложения и полноценное ручное прохождение этим отчётом не подтверждаются.
