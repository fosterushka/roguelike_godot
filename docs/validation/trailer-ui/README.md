# Архив проверки интерфейса прицепов

Описание актуализировано 2026-09-06. Эти снимки сделаны до объединения вкладок убежища и последующих правок машины. Они сохраняют доказательства предыдущего этапа, но не подтверждают вид текущего интерфейса. Актуальное поведение: [покупка прицепов](../../trailers-and-case-opening.md) и [UI](../../ui.md).

Сохранённые захваты использовали Godot Metal, 960×600, русский и английский языки. Изолированным тестовым профилям выдавались кредиты, затем выполнялись обычные покупки, установка оборудования и переход в рейд. Пользовательское сохранение не изменялось.

В записи этапа указаны результаты: `trailer_ui_test.gd` 15/15, `caravan_crew_test.gd` 55/55, `armory_unit_test.gd` 51/51, интеграция каравана 38/38. Это количество проверок внутри отдельных сценариев, не размер нынешнего общего набора. Команды запуска: [testing.md](../../testing.md).

Источник снимков: `tests/trailer_ui_capture.tscn`, десять кадров. После захвата менялись стиль выбранной вкладки и сброс прокрутки, позднее всё убежище. При актуализации документации повторный захват и игровые тесты не выполнялись; снимки и логи сохранены без изменений.
