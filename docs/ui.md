# Интерфейс

Сверено с кодом 2026-09-06. Основные компоненты находятся в [presentation/ui](../presentation/ui).

## Главное меню и убежище

Главное меню построено как компактная текстовая иерархия: Singleplayer, отключённый Multiplayer, Options, Exit. В Singleplayer находятся Raid, Vault и Back. Raid запускает заезд; Vault открывает убежище со всеми вкладками:

| Вкладка EN / RU | Содержимое | Ключ состояния |
| --- | --- | --- |
| Armory / Арсенал | Комплектация, модули, поиск и фильтр | `armory` |
| Stash / Снаряжение | Припасы для следующего рейда | `loadout` |
| Vault / Хранилище | Постоянный запас | `stash` |
| Trade / Торговля | Покупка и продажа по одному предмету | `trade` |
| Base / База | Постоянные улучшения | `upgrades` |
| Tasks / Задания | Поиск, фильтры, принятие и сдача миссий | `quests` |
| Settings / Настройки | Сила тряски камеры | `settings` |

Подпись Stash не означает ключ `stash` в профиле: этот ключ принадлежит постоянному Vault. Названия UI не меняют схему сохранения. Options доступны из главного меню и с паузы; там сохраняются звук, язык и сила тряски камеры.

[hideout_hub.gd](../presentation/ui/hideout_hub.gd) временно помещает существующие панели арсенала и экспедиции в общую область. Режим `set_embedded()` убирает их повторные заголовки и кнопки закрытия. При выходе панели возвращаются к обычному родителю для использования в рейде.

Кредиты и уровень аккаунта видны над всеми вкладками и обновляются после операций. Garage доступен из заголовка; возврат сохраняет выбранную вкладку. Арсенал использует общую строку поиска/фильтра, предпросмотр техники и отдельную прокрутку описания. Таблицы предметов имеют иконки и короткие действия в строке.

## Во время рейда

HUD группирует корпус, топливо, скорость, лом и команды слева внизу. Навыки находятся снизу по центру, карта справа внизу, волна и число врагов сверху. Меню и пауза блокируют игровой ввод. Сенсорное управление включается по наличию сенсорного экрана, а не по ширине окна ПК.

Слоты показывают готовность, цену или причину недоступности. Карта доступна без покупки модуля; установленные уровни радара расширяют возможности. Клавиши приведены в [README](../README.md).

## Общие правила

- Прямоугольные панели, читаемые подписи, компактные отступы; без bubble-элементов.
- Главное меню использует текстовые действия без навигационных иконок. Общие стили: [ui_styles.gd](../presentation/ui/ui_styles.gd).
- 16 иконок созданы GPT Image; файл и исходный запрос находятся в [assets/ui](../assets/ui/README.md).
- Английский является исходным языком; русский переключается без смены профиля. Переводы проходят через [ui_locale.gd](../presentation/ui/ui_locale.gd).
- Изменения размеров проверяются на узком окне и в обоих языках. Проверка размеров headless и просмотр настоящего кадра учитываются отдельно.

Сохранённые кадры и ограничения последней UI-проверки: [compact-ui](validation/compact-ui/README.md). Описание гаража и кейсов: [trailers-and-case-opening.md](trailers-and-case-opening.md).
