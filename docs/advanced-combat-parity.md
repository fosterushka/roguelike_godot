# Боевая система

Сверено с текущим кодом 2026-09-06. Документ описывает Godot-реализацию; полное визуальное совпадение с исходной игрой не заявляется.

| Модуль в `modules/combat/` | Ответственность |
|---|---|
| `combat_model.gd`, `combat_runtime.gd` | Состояние боя, события, синхронизация машины |
| `projectile_rules.gd` | Пересечение траектории с целями, попадания |
| `sidegrade_rules.gd` | Четыре варианта оружия, замедление и пробитие |
| `protocol_rules.gd` | Шесть протоколов, метки, подавление, бонусные выстрелы, Salvage Loop, цепная молния |
| `rocket_rules.gd` | Полёт и разброс ракет |
| `road_fury_rules.gd` | Дрифт, комбо, опасное сближение, таран и отталкивание |
| `mine_rules.gd` | Ограниченные по числу мины, взлом, смена стороны |

Попадания проверяются по порядку вдоль пройденного отрезка. Запрос столкновения с миром обрезается до следующего попадания в сущность: стена за врагом не перехватывает выстрел раньше него. Пробивающий снаряд продолжает оставшийся отрезок.

Позиция, скорость, курс, скольжение и ручник синхронизируются с контроллером машины. Эффекты протоколов потребляют `active_protocols`, `selected_sidegrades` и `treasury_count`; пересборка модулей обновляет действующие протоколы. Низкое здоровье, броня и боевые способности обрабатываются в бою; периодический ремонт установленной мастерской принадлежит progression.

Мировые столкновения, навигация, пять целей Левиафана, машины поддержки и взлом мин подключены. Подробности: [враги](enemy-ai-parity.md), [мины](mine-hacking.md), [помехи](jammer-gameplay-notes.md), [контракт runtime](../modules/session/combat_contract.md).

Проверки: `tests/combat_test.gd`, `advanced_combat_test.gd`, `enemy_ai_test.gd`, `combat_soak_test.gd`. Их наличие не означает новый успешный прогон. Графика, звук и ощущение управления требуют графического запуска.
