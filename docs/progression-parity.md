# Прогрессия и сохранение

Сверено с кодом 2026-09-06.

| Файл | Ответственность |
|---|---|
| `modules/progression/progression.gd` | Покупки и снятие модулей, уровни, выбор улучшений, сборка, сохранение |
| `modules/progression/upgrade_rules.gd` | Характеристики, core-улучшения, протоколы и варианты оружия |
| `modules/progression/contract_progress.gd` | Контракты, счётчики, награды и защита от повторных событий |
| `modules/progression/radar_rules.gd` | Уровни и покупка улучшения радара |
| `infrastructure/persistence/profile_store.gd` | Локальный профиль, миграция и атомарное сохранение |

Создать `Progression.new(optional_profile_path)`, затем вызвать `setup(model)`. После сброса боя вызвать `reset_run()`, при старте `begin_run()`, передавать время через `step(delta)` и события через `on_combat_event(event)`. При закрытии вызвать `flush()`.

`get_shop_state()` возвращает строки модулей, оружия, радара, выбора уровня, протоколов, контрактов и вариантов оружия; строки содержат `id`, `label`, `description`, `cost`, `enabled`, `disabled_reason`. Изменения выполняются через `buy_upgrade(action_id)`, а не прямую правку снимка магазина.

Каждый уровень даёт +24 максимального HP и лечение до 42 HP; следующий порог опыта равен `floor(previous * 1.46 + 40)`. Сначала выбирается бесплатное core-улучшение, затем один draft-вариант. При ожидающем выборе обычные покупки блокируются. Проверки веса, места установки, цены и уникальности выполняются в progression.

Прицепы покупаются по отдельности в гараже базы. Старый action `trailer` не покупает прицеп: строка магазина отключена с пояснением о гараже. Сборка учитывает конкретный вагон, его доступные места и отключённые модули. Мастерская раз в 4 с лечит на 2 HP машину, на которой установлена, если та жива.

Выбранные варианты оружия копируются в состояние заезда; эффекты протоколов и награды за боевой подбор применяет combat. Прогресс контрактов получает события с поколением заезда; мировые задания используют `activity_completed`. Звук и разблокировки сохраняются в профиле.

По умолчанию профиль расположен в `user://iron-caravan-profile.json`. Неуспешное сохранение оставляет `dirty` и повторяется; неизвестная будущая версия открывается только для чтения. Одновременные записи нескольких процессов не объединяются.

Проверки: `tests/progression_test.gd`, `radar_progression_test.gd`. Обновление документа не является новым прогоном. Порядок случайных предложений Godot не гарантирует совпадения с JavaScript при одном seed.
