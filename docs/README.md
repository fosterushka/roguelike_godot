# Документация Iron Caravan

Основной документ для разработки: [PROJECT.md](PROJECT.md). Он объединяет прежние справочники механик, архитектуры, UI, моделей и боевого runtime. Сверка с кодом: 2026-09-08.

- [Проверки и экспорт](testing.md): запуск, подходящие сценарии, требования к результатам.
- [Исходники моделей и пересборка](../assets/models/README.md): локальные инструкции для Blender-ассетов.
- [Архив проверок](ARTIFACTS.md): назначение сохранённых JSON, PNG, логов и старых заметок.
- [Исторический отчёт оптимизации](PERFORMANCE_REPORT.md) и [его данные](performance-measurements.json): измерения конкретного прохода, не текущий FPS.
- [Историческое сравнение моделей](model-revision-report.html): зависит от локальных кадров, не спецификация текущих ассетов.

Прежние тематические parity/pass/notes/implementation-файлы удалены после объединения. Полный каталог миссий остаётся в [data/missions.json](../data/missions.json), без второй ручной копии в Markdown. Подробные численные параметры читаются из владельцев, на которые ссылается PROJECT.md.

При изменении механики обновляйте PROJECT.md; команды проверок поддерживайте в testing.md. Результаты прошлых прогонов не исправляйте задним числом. Если файл из validation отсутствует в чистом checkout, это не ошибка загрузки игры: часть артефактов локальная и игнорируется Git.
