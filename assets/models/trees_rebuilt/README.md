# Простые однотонные деревья

Пропорции прежних деревьев: ель с четырьмя ярусами, берёза с тремя округлыми кронами. Стволы вертикальные.

- `textured_trees.blend`: обе модели отдельно, в редактируемой сцене.
- `spruceTrees.obj` и `birchTrees.obj`: экспорт Y-up.
- `tree_atlas.png`: четыре сплошных цвета без градиентов, коры и листвы; 32×32.
- Игровая модель: `assets/environment/textured_trees.glb`.

Храните OBJ, MTL и PNG вместе. Генератор: `scripts/blender/build_textured_trees.py`.

Ель: 116 треугольников. Берёза: 388. У каждой один объединённый меш и одна поверхность; материал общий. Отдельные дубли моделей для дальнего плана не нужны.

Генератор запускается через Blender MCP, временно создаёт отдельную сцену и сохраняет исходную сцену Blender.
