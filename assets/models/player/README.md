# Военный пикап

Актуализировано по коду и файлам 2026-09-06.

Собственная low-poly модель создаётся `scripts/blender/build_player.py` и `pickup_geometry.py` без импорта старой JSON-геометрии. Она включает открытый кузов, защиту фар, силовой бампер, люк и канистру.

- `player.blend`: редактируемый корпус и четыре колеса, упакованная палитра.
- `player.obj`, `player.mtl`, `palette.png`: переносимая статическая модель и цвета; хранить вместе.
- `preview.png`, `preview_rear.png`: сохранённые виды спереди и сзади.
- `stats.json`: статистика экспорта, размеры и координаты колёс.

Пять mesh-объектов используют два уникальных меша и один материал. Четыре колеса имеют отдельные родительские pivot-узлы и общую геометрию. UV выбирают цвета из палитры 32×32; это не развёртка для рисования уникальной текстуры.

Blender: Z-up, перед машины направлен по -Y. OBJ: Y-up, forward -Z. OBJ не сохраняет родительские связи и общие datablock-ссылки. Камеры, свет и пол предпросмотра исключены из экспорта модели.

Игра и арсенал используют `assets/vehicles/military_pickup.glb`. `presentation/vehicles/military_pickup.gd` подключает GLB через `wheeled_rig.gd`, извлекает `PIVOT_WHEEL_FRONT_LEFT`, `FRONT_RIGHT`, `REAR_LEFT`, `REAR_RIGHT` и связывает их с рулением и подвеской. Масштаб и игровые размеры задаются в `modules/caravan/player_dimensions.gd`; при изменении геометрии нужно сохранять этот контракт.

Пересборка из корня проекта:

```sh
/Applications/Blender.app/Contents/MacOS/Blender --background --factory-startup --python-exit-code 1 --python scripts/blender/build_player.py
```

Команда перезаписывает экспорт. Ручные варианты сохраняйте отдельно. Общая проверка экспорта описана в [каталоге моделей](../README.md).
